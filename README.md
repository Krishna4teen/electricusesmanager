# Electricusesmanager

Build ECO-WATT, a complete responsive full-stack Household Electricity Consumption Analyzer using Lovable Cloud for persistent storage. Implement the complete requested product: functional pages (Home, Analyze, Appliances, History, Tips, About), editable multi-appliance input with validation and accurate daily/monthly/yearly/cost calculations, dynamic charts, consumption status criteria with explanation, data-driven rule-based recommendations ranked by consumption, reduction plan, save/load/delete analysis history and trend comparison, full printable report, responsive accessible eco-friendly UI. Do not stop at a static UI. Enable Lovable Cloud first and use the database to persist completed analysis snapshots and appliance data. Test known AC and fan calculation examples before completing.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://electricusesmanager.lovable.app
